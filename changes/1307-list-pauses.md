section: Breaking
issue: 1307
---

**`app.listPauses` is a `Page` listing with a tenant scope and more filters** (#1307e): `listPauses(...TenantListArgs<TApp, PausesQuery>)` returns the standard `Page<ListedPause>` (`{ items, nextCursor? }`, `{ cursor, limit }`) like `listExecutions`; `PausesPage` (`{ pauses, next }`) and the `after` field are gone, and a query field the listing does not have is refused (`ValidationError.DtoInvalid`) instead of ignored. The scope is `{ tenantId }` or `{ allTenants: true }` (never both; required when the application declares a `tenantContext`, else `"default"`). New filters: `channel` (a `@Channel` class or its name, read from the decorator, no registry), `assignee` (one of a pool), `externalRef`, `target` as a class or its name, `expiringBefore` as `Date` or ISO text. `includePauseIds` (default `false`) shows the `pauseId` of delegated pauses too — a pause's id is the right to answer it, so by default only an `Owner` pause's id is listed, as in `result.pending`. **Stores:** `PauseFilter` gains `channel`, `assignee` and `externalRef`, and `PausedExecutionRepository` gains the abstract `findPageOfAllTenants(filter, limit, after?)`; SQLite reads both filters from the pause's JSON and indexes the reference. The `@agboss/postgres` and `@agboss/mongodb` filters follow in their repositories.

**Unknown query fields are refused by every listing** (#1307e): `listExecutions` and `pendingOutboundCallsOf` now reject a field their query does not have (`after`, `role`, `offset`, a typo) with `ValidationError.DtoInvalid` naming it, like `listPauses`, instead of ignoring it. (`listOutboundCalls` and `listAuditEvents` do not exist yet; their reshape takes the same shared `refuseUnknownFields`.)

**`ListedPause.tenantId`** (#1307e): every listed pause names its tenant, so an `allTenants` page can be acted on (`resume`, `reassignPause`, `setPauseTimeout` need `{ tenantId }`). **`PauseError.UnknownPause` and two logs name a pause by its key** (`pauseKeyOf`), never its raw id: a pause id resumed under the wrong tenant no longer reaches an error message or a log.
