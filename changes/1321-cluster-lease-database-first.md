**Under `@ClusterStorage` the database's lease row is the authority for the token, the stop mark, the external pause and its fence, written before the cluster acknowledges** (#1321e, D6). Added: `ClusterExecutionLeaseRepository` (the order of the two writes: a take is mirrored into the row before it is handed out, an end is written to the row before the cluster's key changes, a mark is written to the row and then pushed; a failure to mirror ends the call, fail closed), `ClusterLeaseCoordinator` (what a cluster driver implements), `ClusterLeaseMirror` (`syncClusterLease`, `endClusterLease`, `mirroredLeaseOf`: what a database lease store mirrors a cluster lease with), `ClusterLeaseSyncOutcome`, `MirroredLeaseState`, `CLUSTER_LEASE_EXPIRY`, `InMemoryCluster` (a double), `StoreError.ClusterLeaseBehind` (`store.cluster-lease-behind`), the contract `executionLeaseClusterContract` (`@agboss/core/testing/contracts`). Changed: `ExecutionIdStore` also carries `requestPause`, `unpause`, `pauseOf`, `markedOf` and the mirror; the fencing stores are checked against the lease store bound to `EXECUTION_ID_STORE` (`[application.store-backend-mismatch]` no longer pairs them with the cluster's lease store).
**Store follow-up (T3):** the Redis lease store extends `ClusterExecutionLeaseRepository` with a `ClusterLeaseCoordinator` (Lua scripts, `raiseEpoch` for the durable epoch sync, `publishMarks` as cache and Pub/Sub, no `PEXPIRE` on a paused release); Postgres, MongoDB implement `ClusterLeaseMirror` on the lease row (state `'c'`: held, `expires_at` at the far future, `fenced_through_token` and the marks kept, retire written before the cluster's key changes); they pass `executionLeaseClusterContract`.
