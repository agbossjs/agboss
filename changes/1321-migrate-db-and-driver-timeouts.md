**`agboss migrate db` and the durations of a networked driver** (#1321f, core side). Added: `agboss migrate db [--application <path>] [--profile <list>] [--allow-live-leases]` runs the migration of the application's `@DatabaseStorage` driver on its resolved settings, the profile's config loaded before the storage is resolved (a driver with no migration, SQLite, migrates nothing; live leases refuse it with `store.live-leases` unless `--allow-live-leases`, which only the command line can say); `StorageDriver.migrate`, `StorageMigrate`, `StorageMigration`, `StorageMigrationOptions`, `DriverTimeouts` (`watchLiveness`, `commandTimeout`, `idleInTransactionTimeout`, each `Milliseconds`, `env.duration` gives one), `DEFAULT_WATCH_LIVENESS` (`sec(10)`), in `@agboss/core/stores`.
**Store follow-up (T4):** the store packages' drivers pass `migrate`, take `DriverTimeouts` in place of `watchLivenessSeconds` / `commandTimeout` numbers and `DEFAULT_WATCH_LIVENESS_SECONDS`, drop the `allowMigrationWithLiveLeases` setting, remove the `agboss-postgres` / `agboss-mongodb` bins and their flag parsers, add `migrateMongo`, replace `client.topology` with SDAM events (`MongoDriverInternalsError` gone), route background `pool.on("error")` / client errors to `Logger`, wrap `RedisClient` in an exported interface, move `@langchain/*` from peer to dependencies, and unexport the internals (`StepIndexResult`, `PostgresStepIndexError`, `checkpointMigrations`, `Collections`, the Postgres/Mongo pause helper classes); Postgres adds the missing A2A and audit repositories (P6.3).
