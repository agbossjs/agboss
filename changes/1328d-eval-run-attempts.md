**`runEvalSuite`, `compareEvalSuite`, `beforeAttempt` / `afterAttempt`, `[eval.judge-missing-provider]`** (#1328, part d): `runEvalSuite(Application, Suite, { profile?, env?, runs?, chaos?, metamorphic?, tracerProvider?, processEnv? })` builds the application, runs the suite and closes it; `compareEvalSuite(Application, Suite, { variants })` runs it once per variant (`{ name, profile? }`) and reads each against the first (`EvalSuiteComparison`, `EvalVariantReport` with `executionUsd`, `judgeUsd`, `latencyP50`, `latencyP95`). `beforeAttempt` / `afterAttempt` on `@EvalSuite` and `evalCase` run around every repetition of a case (the suite's before the case's, the case's after before the suite's); a hook that throws fails that run (`eval.attempt-hook-failed`). A model judge with no provider pinned (`@Judge`, `@EvalSuite`, `@Application`) is `[eval.judge-missing-provider]`. A judge's calls are recorded as `judgeUsd` and are no longer billed to the application's budgets. `EvalToolCallTrace` has `startedAt` / `endedAt` `Date`s. `agboss eval run --baseline` warns when the baseline's profile, models or judges differ from the run's; `agboss generate eval-case --from-execution` writes the answered pauses (`answerPause`) and, for a stopped or cancelled run, its `expectedStatus`. `runEvalSuite` of the CLI's runner is `runSuiteOn` of `@agboss/core/internal`.
