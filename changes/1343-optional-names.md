**`name` and `description` are optional on the components that nothing stores by name; the `-kind` suffix is gone from them** (#1343): `@HealthCheck`, `@PauseListener`, `@WorkingCalendar`, `@ToolInterceptor`, `@InputGuardrail`, `@OutputGuardrail`, `@PiiPolicy`, `@Arbiter`, `@ChannelInterpreter`, `@Reranker`, `@ModelProvider` and `@Judge` take `name?` (default: the class name in kebab-case, `CrmHealthCheck` → `crm-health-check`) and `description?`. `[name.kind-suffix]` is no longer raised for them, for `@Tool` / `@McpTool`, `@A2AAgent` or `@A2AExpose` (a tool's name keeps the model-API character and length rules, `[tool.name-invalid]`, `[tool.name-too-long]`); a name that is not kebab-case is `[name.not-kebab-case]`. `@Workflow`, `@WorkflowStart`, `@WorkflowFinish`, `@Agent`, `@Action`, `@Router`, `@ChannelRole`, `@Application`, `@Budget`, `@EvalSuite` and `@Compaction` keep a required `name` ending with its kind. `NameKind` loses `Tool`, `Arbiter`, `ModelProvider`, `ReplyInterpreter`, `HealthCheck`, `PauseListener`, `WorkingCalendar`, `A2AAgent` and `A2AExpose`. Migration: nothing breaks for a name you wrote, except that a name which is not kebab-case now fails assembly; leave `name` out to take the class name.
